# Доставка еды

Поток заказа:
1. POST /orders — клиент выбирает блюда
2. Система ищет ближайшего свободного курьера
3. Курьер блокируется (available=false)
4. POST /orders/{id}/deliver — курьер свободен

KPI:
- Среднее время доставки (created → delivered)
- Число заказов курьера
- Топ ресторанов по выручке
